# Project Administration Materials

本目录保存毕业设计过程管理材料。

## Layout

- `original_forms/`: 早期原始过程材料，包括任务书、开题报告、开题答辩、中期报告和外文文献翻译。
- `signed_documents/`: 已签字或正式 PDF/Word 材料，包括任务书、开题审查、中期检查、验收表和题目变更说明。
- `final_documents/`: 结题阶段从正式资料盒补充归档的材料，包括答辩资格审查、评阅、答辩小组意见、成绩组成表、外文翻译封面和中期检查文件。

文件级来源和 SHA-256 校验见 `materials/manifests/`。
