# Materials

本目录保存毕业设计最终提交、答辩、过程管理和质量检查材料。

## Layout

- `thesis/`: 最终论文 PDF 和论文矢量图。
- `defense/`: 结题答辩 PDF 与答辩材料说明。
- `project_admin/`: 任务书、开题、中期、外文翻译、答辩资格审查、评阅、答辩意见、成绩组成表等过程材料。
- `quality/`: AIGC 检测和质量检查材料。
- `manifests/`: 材料来源、目标路径、大小和 SHA-256 校验清单。

新增正式材料应归入上述长期目录，并同步更新 `docs/thesis_material_index_zh.md` 和对应 manifest。
