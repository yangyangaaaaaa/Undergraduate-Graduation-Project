# Reward Case Figures

本目录保存奖励机制相关的精选可视化材料，用于解释训练阶段奖励如何影响策略学习。

## Layout

- `01_action_attribution/`: 训练日志中的动作奖励归因图。
- `02_route_reward_cases/`: 路线与奖励曲线案例。
- `03_evolution_cases/`: 同一任务在训练早期和后期的路线演化。
- `04_c4_wandering_failures/`: C4 短距离失败边界案例。
- `05_reward_mechanism_axis/`: 奖励机制分阶段直线轴图。

这些图解释训练阶段信号，不表示测试阶段仍调用奖励函数。配套报告见 `results/reports/reward_stepwise_global_analysis_zh.md`、`results/reports/reward_action_attribution_cases_zh.md` 和 `results/reports/reward_guided_ppt_focus_cases_zh.md`。
