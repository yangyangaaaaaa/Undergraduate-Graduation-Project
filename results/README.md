# Results

This directory stores the organized results used by the thesis.

## Layout

- `tables/main_benchmark/`: MM-GAG, MASA, SwissView, xBD, AirLoc, and official-retrain comparison tables.
- `tables/ablation/`: mechanism, reward, and gate-function ablation tables.
- `tables/appendix/`: training dataset, parameter sensitivity, validation-distance, and seed-stability tables.
- `tables/ultra_long/`: long-distance grid tests.
- `figures/`: thesis figures and redraw assets.
- `reports/`: Chinese summaries and protocol notes.

Large checkpoints and raw datasets are not stored here. Result tables keep run names and checkpoint paths so the source experiment can be matched to the saved model.
